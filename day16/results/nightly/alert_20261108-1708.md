# 夜間テスト アラート報告 (2026-11-08 17:08:31)

## 1. 何が起きたか
- `powershell -NoProfile -File test/run_host_tests.ps1` を実行したところ、テスト結果が **FAIL** となりました。
- 全6テスト中4テスト合格、2テスト（アサーション単位では63件中5件）が失敗しました。
- 失敗したテスト:
  - `test_raw_to_battery_mv` (4アサーション失敗)
    - line 100: 4095 raw -> expected 6200, got 3100
    - line 101: 2048 raw -> expected 3100, got 1550
    - line 102: 1981 raw -> expected 2998, got 1499
    - line 106: raw > 4095 clamped -> expected 6200, got 3100
  - `test_main_app_and_deep_sleep` (1アサーション失敗)
    - line 250: log contains 電池 2998 mV、ドア 開 (実際には「電池 1499 mV、ドア 開」が出力)

## 2. 考えられる原因
- `git diff HEAD -- main test` の結果、`main/door_sensor.c` 内の `door_raw_to_battery_mv()` に変更がありました。
- 差分内容:
  ```diff
  --- a/day14/door_sensor/main/door_sensor.c
  +++ b/day14/door_sensor/main/door_sensor.c
  @@ -20,7 +20,7 @@ int door_raw_to_battery_mv(int raw)
           raw = 4095;
       }
       // 12dB のおおよその換算（0〜4095 → 0〜3100 mV）。分圧の分を 2 倍で戻す
  -    return raw * 3100 / 4095 * 2;
  +    return raw * 3100 / 4095;
   }
  ```
- コメント「分圧の分を 2 倍で戻す」にある通り、回路側の分圧（1/2）を補正するための `* 2` が削除されてしまっています。
- これにより電池電圧の計算結果が常に本来の半分（1/2）になり、センサーが電池切れ・低電圧と誤判定するなどの不具合につながります。

## 3. 直し方の提案
- `main/door_sensor.c` の `door_raw_to_battery_mv()` の戻り値計算に `* 2` を復元してください。
  ```c
  return raw * 3100 / 4095 * 2;
  ```
- 修正後、`powershell -NoProfile -File test/run_host_tests.ps1` を実行し、全テストが PASS することを確認してください。
