## 中身
- all の引用：S3 の問は S3 だけを引用。Q4 は ESP32 と S3（VDD3P3_CPU は両方にある）、Q6 は C6 と S3（比べる問）。X6（「ESP32」）は ESP32 だけ引用して初代の 10 µA を答え、ほかの型番に触れない（△）
- whole の X5 ×：「資料には、ESP32-S3が Zigbee や Thread に対応しているかについての記載はありません」とだけ。s3 の X5 ○ は「対応しているのは 802.11b/g/n と Bluetooth 5 (LE)/Mesh」と並べてから「Zigbee や Thread の記載はありません」。資料の範囲は同じ。差は対応しているものを並べたか（判定は LLM）
- whole の X3 △ も同じ形（「BR/EDR の記載はありません」だけ）。File Search の s3・all は「LE のみ」「使用できません」
- s3 の Q4 △：推奨動作条件 3.0〜3.6 V と eFuse の注意は正しいが、絶対最大定格にも触れていない
