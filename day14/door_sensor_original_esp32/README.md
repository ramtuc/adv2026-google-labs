# 電池で動くドアセンサー（ESP-IDF）

ESP32-DevKitC（ESP32-WROOM-32）で作った、Deep-sleep で電池を長持ちさせるドアセンサーです。

- 10 分ごと、呼び出しボタン、ドアノブのタッチで起きる
- 起きたら電池の電圧とドアの開閉を読み、ログに出してまた寝る
- 起きた回数とドアの前回の状態は RTC メモリに残す

## 配線（ESP32-DevKitC）

| 部品 | ピン | メモ |
| --- | --- | --- |
| 呼び出しボタン | GPIO33 | 押すと LOW（内部プルアップ） |
| ドアのリードスイッチ | GPIO34 | 10kΩ で 3.3V に外部プルアップ。閉じると LOW |
| 電池の電圧 | GPIO35（ADC1_CH7） | 100kΩ ＋ 100kΩ で 1/2 に分圧 |
| タッチパッド | GPIO4（T0） | ドアノブに貼った銅箔につなぐ |

## ビルド

ESP-IDF v5.5 で確認しています。

```
idf.py set-target esp32
idf.py build
idf.py -p <ポート> flash monitor
```
